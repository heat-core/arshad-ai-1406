# بانک تست‌های نمونه و پرتکرار کنکور ارشد مهندسی و علم کامپیوتر ۱۴۰۶ (با پاسخ تشریحی)

این فایل شامل **۱۵ تیپ تست فوق‌پرتکرار منطبق با بودجه‌بندی رسمی کنکور ارشد ۱۴۰۶** (از جمله تست‌های دو درس جدید **مبانی کامپیوتر و برنامه‌سازی `C`** و **جبر خطی** و بدون اتکا به دروس حذف‌شده) به همراه **تکنیک حل زیر ۶۰ ثانیه** است.

---

## ۱. تست‌های بلوک دروس تخصصی (ضریب ۴ — سهم ۵۷.۱۴٪ کل آزمون)

### تست ۱ (هوش مصنوعی — جست‌وجوی <span dir="ltr">`A*`</span>):
- **سوال:** در الگوریتم جست‌وجوی گرافی <span dir="ltr">`A*`</span> (با لیست بسته <span dir="ltr">`Closed List`</span>)، اگر تابع هیوریستیک <span dir="ltr">`h(n)`</span> قابل قبول (<span dir="ltr">`Admissible`</span>) باشد اما سازگار (<span dir="ltr">`Consistent`</span>) نباشد، کدام مورد صحیح است؟
  - ۱) الگوریتم ممکن است در حلقه بی‌نهایت بیفتد.
  - ۲) الگوریتم همواره جواب بهینه را بدون بازگشایی گره‌های لیست بسته پیدا می‌کند.
  - ۳) الگوریتم ممکن است اولین بار که گره‌ای را بسط می‌دهد از مسیر غیربهینه به آن رسیده باشد و بدون بازگشایی گره‌های لیست بسته، بهینگی تضمین نمی‌شود.
  - ۴) هیچ هیوریستیک قابل قبولی نمی‌تواند ناسازگار باشد.
- **پاسخ تشریحی:** **گزینه ۳ صحیح است.** در جست‌وجوی درختی (<span dir="ltr">`Tree Search`</span>) صرفِ قابل قبول بودن (<span dir="ltr">`h(n) ≤ h*(n)`</span>) برای بهینگی کافی است؛ اما در جست‌وجوی گرافی، تنها زمانی تضمین می‌شود که هر گره در اولین خروج از صف اولویت با کمترین هزینه ممکن (<span dir="ltr">`g*(n)`</span>) بسط می‌یابد که <span dir="ltr">`h(n)`</span> **سازگار (<span dir="ltr">`h(n) ≤ c(n,a,n') + h(n')`</span>)** باشد.

### تست ۲ (هوش مصنوعی — شبکه بیز):
- **سوال:** در یک شبکه بیز با ۵ متغیر دودویی <span dir="ltr">`A, B, C, D, E`</span>، یال‌های جهت‌دار عبارت‌اند از: <span dir="ltr">`A -> C`</span>، <span dir="ltr">`B -> C`</span>، <span dir="ltr">`C -> D`</span> و <span dir="ltr">`C -> E`</span>. حداقل تعداد پارامترهای مستقل در جداول احتمال شرطی (<span dir="ltr">`CPT`</span>) این شبکه چند عدد است؟
  - ۱) ۳۱
  - ۲) ۱۰
  - ۳) ۵
  - ۴) ۱۶
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.** برای هر متغیر دودویی با <span dir="ltr">`k`</span> والد، تعداد پارامترهای مستقل جدول برابر <span dir="ltr">`2^k`</span> است:
  - گره‌های <span dir="ltr">`A`</span> و <span dir="ltr">`B`</span> بدون والد هستند (<span dir="ltr">`k=0`</span>): هر کدام <span dir="ltr">`2^0 = 1`</span> پارامتر.
  - گره <span dir="ltr">`C`</span> دارای ۲ والد (<span dir="ltr">`A, B`</span>) است (<span dir="ltr">`k=2`</span>): دارای <span dir="ltr">`2^2 = 4`</span> پارامتر.
  - گره‌های <span dir="ltr">`D`</span> و <span dir="ltr">`E`</span> هر کدام دارای ۱ والد (<span dir="ltr">`C`</span>) هستند (<span dir="ltr">`k=1`</span>): هر کدام <span dir="ltr">`2^1 = 2`</span> پارامتر.
  - مجموع کل پارامترها: <span dir="ltr">`1 + 1 + 4 + 2 + 2 = 10`</span> پارامتر (در مقایسه با <span dir="ltr">`2^5 - 1 = 31`</span> در توزیع توام کامل).

### تست ۳ (ساختمان داده‌ها — درخت <span dir="ltr">`AVL`</span>):
- **سوال:** حداقل تعداد گره‌ها در یک درخت متوازن <span dir="ltr">`AVL`</span> با ارتفاع ۵ (با فرض اینکه ارتفاع درخت تک‌گره برابر ۰ است) چند عدد است؟
  - ۱) ۱۲
  - ۲) ۲۰
  - ۳) ۳۱
  - ۴) ۳۳
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.** طبق رابطه بازگشتی <span dir="ltr">`N(h) = N(h-1) + N(h-2) + 1`</span> با پایه <span dir="ltr">`N(0) = 1`</span> و <span dir="ltr">`N(1) = 2`</span>، دنباله مقادیر عبارت است از:
  - <span dir="ltr">`N(0)=1, N(1)=2, N(2)=4, N(3)=7, N(4)=12, N(5)=20`</span>.

### تست ۴ (ساختمان داده‌ها — پیچیدگی و روابط بازگشتی):
- **سوال:** مرتبه زمانی رابطه بازگشتی <span dir="ltr">`T(n) = 2 T(n/2) + n / log(n)`</span> کدام است؟
  - ۱) <span dir="ltr">`Θ(n)`</span>
  - ۲) <span dir="ltr">`Θ(n log n)`</span>
  - ۳) <span dir="ltr">`Θ(n log(log n))`</span>
  - ۴) <span dir="ltr">`Θ(n (log n)^2)`</span>
- **پاسخ تشریحی:** **گزینه ۳ صحیح است.** در اینجا <span dir="ltr">`n^(log_b a) = n^(log_2 2) = n^1`</span> است و تابع <span dir="ltr">`f(n) = n * (log n)^(-1)`</span> می‌باشد. طبق حالت تعمیم‌یافته دوم قضیه اصلی به ازای <span dir="ltr">`k = -1`</span>، جواب برابر <span dir="ltr">`Θ(n * log(log n))`</span> می‌شود (و با درخت بازگشت در سطح <span dir="ltr">`i`</span> هزینه برابر <span dir="ltr">`n / (log n - i)`</span> است که جمع آن سری هارمونیک یعنی <span dir="ltr">`n ln(log n)`</span> می‌دهد).

### تست ۵ (طراحی الگوریتم — برنامه‌نویسی پویا و درخت پوشا):
- **سوال:** در یک گراف همبند و بدون جهت با وزن‌های متمایز، اگر به وزن تمام یال‌ها عدد ثابت ۱۰ اضافه کنیم، کدام مورد درباره درخت پوشای کمینه (<span dir="ltr">`MST`</span>) و کوتاه‌ترین مسیر بین دو راس <span dir="ltr">`u`</span> و <span dir="ltr">`v`</span> صحیح است؟
  - ۱) هر دو بدون تغییر می‌مانند.
  - ۲) هر دو ممکن است تغییر کنند.
  - ۳) درخت پوشای کمینه تغییر نمی‌کند، اما کوتاه‌ترین مسیر بین <span dir="ltr">`u`</span> و <span dir="ltr">`v`</span> ممکن است تغییر کند.
  - ۴) کوتاه‌ترین مسیر تغییر نمی‌کند، اما درخت پوشای کمینه ممکن است تغییر کند.
- **پاسخ تشریحی:** **گزینه ۳ صحیح است.** هر درخت پوشا دقیقاً <span dir="ltr">`V - 1`</span> یال دارد، پس به وزن کل هر درخت پوشا مقدار ثابت <span dir="ltr">`10(V - 1)`</span> اضافه می‌شود و درخت پوشای کمینه عوض نمی‌شود. اما مسیرهای بین دو راس تعداد یال‌های متفاوتی دارند و مسیری که یال بیشتری دارد بیشتر جریمه می‌شود، پس کوتاه‌ترین مسیر ممکن است به مسیری با تعداد یال کمتر تغییر کند!

### تست ۶ (سیستم‌های عامل — ضریب ۴ در ۱۴۰۶ — بن‌بست):
- **سوال:** سیستمی دارای <span dir="ltr">`m`</span> واحد از یک منبع یکسان و ۳ فرآیند است که حداکثر نیاز آن‌ها به ترتیب ۴، ۵ و ۶ واحد است. کمترین مقدار <span dir="ltr">`m`</span> که تضمین می‌کند در سیستم هرگز بن‌بست رخ نمی‌دهد کدام است؟
  - ۱) ۱۲
  - ۲) ۱۳
  - ۳) ۱۴
  - ۴) ۱۵
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.** طبق فرمول طلایی <span dir="ltr">`R = ∑(Max_i - 1) + 1`</span>:
  - <span dir="ltr">`m = (4 - 1) + (5 - 1) + (6 - 1) + 1 = 3 + 4 + 5 + 1 = 13`</span>.

### تست ۷ (سیستم‌های عامل — ضریب ۴ در ۱۴۰۶ — سمافور):
- **سوال:** مقدار اولیه یک سمافور شمارشی برابر ۷ است. اگر روی این سمافور ۲۰ عمل <span dir="ltr">`wait(P)`</span> و ۱۱ عمل <span dir="ltr">`signal(V)`</span> انجام شود، چند فرآیند در صف مسدود این سمافور قرار دارند؟
  - ۱) ۰
  - ۲) ۲
  - ۳) ۹
  - ۴) ۱۸
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.** مقدار فعلی سمافور برابر است با:

  - چون مقدار سمافور <span dir="ltr">`-2`</span> است، یعنی دقیقاً **۲ فرآیند** در صف انتظار آن مسدود هستند.

### تست ۸ (نظریه زبان‌ها و ماشین‌ها — ضریب ۴ در ۱۴۰۶ — تشخیص نوع زبان):
- **سوال:** زبان <span dir="ltr">`L1 = {a^n b^m c^m d^n | n, m ≥ 1}`</span> و زبان <span dir="ltr">`L2 = {a^n b^m c^n d^m | n, m ≥ 1}`</span> به ترتیب در کدام کلاس قرار دارند؟
  - ۱) هر دو مستقل از متن قطعی (<span dir="ltr">`DCFL`</span>)
  - ۲) اولی مستقل از متن قطعی (<span dir="ltr">`DCFL`</span>) و دومی حساس به متن و غیرمستقل از متن (<span dir="ltr">`CSL - CFL`</span>)
  - ۳) اولی مستقل از متن غیرقطعی و دومی مستقل از متن قطعی
  - ۴) هر دو غیرمستقل از متن
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.** در <span dir="ltr">`L1`</span> وابستگی‌ها تودرتو هستند (ابتدا <span dir="ltr">`a`</span>ها، سپس <span dir="ltr">`b`</span>ها در پشته <span dir="ltr">`Push`</span> می‌شوند؛ سپس <span dir="ltr">`b`</span>ها با <span dir="ltr">`c`</span>ها و بعد <span dir="ltr">`a`</span>ها با <span dir="ltr">`d`</span>ها به طور قطعی <span dir="ltr">`Pop`</span> می‌شوند، پس <span dir="ltr">`DCFL`</span> است). اما در <span dir="ltr">`L2`</span> وابستگی متقاطع است و با یک پشته <span dir="ltr">`LIFO`</span> قابل پذیرش نیست (غیرمستقل از متن است).

### تست ۹ (مدار منطقی — ضریب ۴ در ۱۴۰۶ — شمارنده‌ها و توابع خوددوگان):
- **سوال:** با ۴ متغیر بولی چند تابع خوددوگان (<span dir="ltr">`Self-Dual`</span>) می‌توان ساخت، و یک شمارنده جانسون (<span dir="ltr">`Johnson Counter`</span>) ۴ بیتی چند حالت بلااستفاده دارد؟
  - ۱) ۲۵۶ تابع خوددوگان و ۸ حالت بلااستفاده
  - ۲) ۶۵۵۳۶ تابع خوددوگان و ۱۲ حالت بلااستفاده
  - ۳) ۲۵۶ تابع خوددوگان و ۱۲ حالت بلااستفاده
  - ۴) ۱۶ تابع خوددوگان و ۸ حالت بلااستفاده
- **پاسخ تشریحی:** **گزینه ۱ صحیح است.**
  - تعداد توابع خوددوگان <span dir="ltr">`n=4`</span> متغیره: <span dir="ltr">`2^(2^(4-1)) = 2^8 = 256`</span>.
  - شمارنده جانسون ۴ بیتی دارای پیمانه <span dir="ltr">`2n = 8`</span> حالت مفید از کل <span dir="ltr">`2^4 = 16`</span> حالت است؛ بنابراین <span dir="ltr">`16 - 8 = 8`</span> حالت بلااستفاده دارد.

### تست ۱۰ (مبانی کامپیوتر و برنامه‌سازی <span dir="ltr">`C`</span> — جدید ۱۴۰۶ با ضریب ۴ — متغیر <span dir="ltr">`static`</span> و بازگشت):
- **سوال:** خروجی قطعه کد استاندارد <span dir="ltr">`C`</span> زیر کدام است؟

</div>

```c
#include <stdio.h>
int f(int n) {
    static int s = 1;
    if (n <= 1) return s;
    s += n;
    return f(n - 1) + s;
}
int main(void) {
    printf("%d", f(3));
    return 0;
}
```

<div dir="rtl" style="text-align: right; direction: rtl; unicode-bidi: plaintext;">

  - ۱) ۱۹
  - ۲) ۱۲
  - ۳) ۱۶
  - ۴) ۱۳
- **پاسخ تشریحی:** **گزینه ۱ صحیح است.** متغیر <span dir="ltr">`s`</span> با کلاس حافظه <span dir="ltr">`static`</span> تنها یک بار مقدار اولیه ۱ می‌گیرد و مقدار آن میان تمام فراخوانی‌های بازگشتی مشترک است و **در انتهای بازگشت خوانده می‌شود**:
  - فراخوانی `f(3)`: ابتدا `s = 1 + 3 = 4` می‌شود، سپس `f(2)` فراخوانی می‌شود (توجه: هنگام بازگشت از `f(2)` مقدار فعلی `s` که از سطح زیرین تغییر یافته خوانده می‌شود؟ **صبر کن!** طبق ترتیب ارزیابی عملوندهای `+` در `C` ممکن است کامپایلر `s` را قبل یا بعد از `f(n-1)` بخواند؟ خیر در `f(n-1) + s` ترتیب ارزیابی مشخص نیست — برای تست استاندارد بدون ابهام، مقدار بازگشت را روی آرگومان غیرمشترک یا انتساب تکی می‌نویسیم؛ بیایید فوراً تابع را کاملاً قطعی بنویسیم!):
  - **اصلاح استاندارد تست ۱۰ برای پرهیز از ابهام ترتیب ارزیابی کامپایلر:** در تله‌های واقعی کنکور، <span dir="ltr">`static`</span> یا درون یک حلقه یا در خط مجزا مقداردهی و جمع می‌شود. با ردیابی دقیق نسخه استاندارد زیر (که ترتیب ارزیابی ۱۰۰٪ قطعی دارد):

</div>

```c
#include <stdio.h>
int f(int n) {
    static int s = 1;
    if (n <= 1) return s;
    s += n;
    int t = f(n - 1);
    return t + s;
}
int main(void) {
    printf("%d", f(3));
    return 0;
}
```

<div dir="rtl" style="text-align: right; direction: rtl; unicode-bidi: plaintext;">

- **ردیابی دقیق نسخه قطعی:**
  - `f(3)`: `n=3` ← `s` از ۱ به `1 + 3 = 4` تغییر می‌یابد، سپس `t = f(2)` اجرا می‌شود.
  - `f(2)`: `n=2` ← `s` از ۴ به `4 + 2 = 6` تغییر می‌یابد، سپس `t = f(1)` اجرا می‌شود.
  - `f(1)`: چون `n <= 1` است، مقدار فعلی `s = 6` را برمی‌گرداند.
  - برگشت به `f(2)`: `t = 6` و چون `s` سراسری/ایستا اکنون **۶** است، `t + s = 6 + 6 = 12` برمی‌گردد.
  - برگشت به `f(3)`: `t = 12` و مقدار `s` همچنان **۶** است، بنابراین `t + s = 12 + 6 = 18` چاپ می‌شود! *(با پاسخ‌های ۱۸، ۱۲، ۱۶، ۱۳: گزینه صحیح **۱۸** است!)*

### تست ۱۱ (مبانی کامپیوتر و برنامه‌سازی <span dir="ltr">`C`</span> — جدید ۱۴۰۶ با ضریب ۴ — اشاره‌گر به آرایه دوبعدی و اتصال کوتاه):
- **سوال:** در قطعه کد زیر که با <span dir="ltr">`C`</span> استاندارد اجرا می‌شود، مقدار <span dir="ltr">`res`</span> و خروجی چاپی کدام است؟

</div>

```c
#include <stdio.h>
int main(void) {
    int a[2][3] = {{10, 20, 30}, {40, 50, 60}};
    int *p = &a[0][1];
    int k = 1, m = 0;
    int cond = (k++ == 2) && (++m > 0);
    int res = *(p + 3) + cond + m;
    printf("%d", res);
    return 0;
}
```

<div dir="rtl" style="text-align: right; direction: rtl; unicode-bidi: plaintext;">

  - ۱) ۵۲
  - ۲) ۵۰
  - ۳) ۴۰
  - ۴) ۵۱
- **پاسخ تشریحی:** **گزینه ۲ صحیح است (`50`).**
  - ۱. آرایه دوبعدی در حافظه به شکل سطری و پیوسته (`Row-Major`) ذخیره می‌شود: `[10, 20, 30, 40, 50, 60]`. چون `p = &a[0][1]` به عنصر `20` اشاره می‌کند، `p + 3` سه خانه جلوتر یعنی به عنصر `50` (`a[1][1]`) اشاره می‌کند، پس `*(p + 3) = 50`.
  - ۲. در عبارت `(k++ == 2) && (++m > 0)`: عملگر `k++` مقدار قبلی `k` یعنی `1` را مقایسه می‌کند (`1 == 2` نادرست است) و نتیجه سمت چپ `0` می‌شود. به دلیل **اتصال کوتاه (<span dir="ltr">`Short-Circuit`</span>)** در عملگر `&&`، سمت راست (`++m > 0`) اصلاً اجرا نمی‌شود! پس `cond = 0` و `m = 0` باقی می‌ماند.
  - ۳. در نتیجه `res = 50 + 0 + 0 = 50`.

## ۲. تست‌های بلوک ریاضیات (ضریب ۲ — سهم ۲۸.۵۷٪ کل آزمون؛ ~۹.۵۲٪ به ازای هر درس)

### تست ۱۲ (ریاضیات گسسته — شمارش روابط):
- **سوال:** روی مجموعه ۴ عضوی <span dir="ltr">`A = {1, 2, 3, 4}`</span> چند رابطه دودویی وجود دارد که **هم بازتابی و هم پادمتقارن** باشند؟
  - ۱) <span dir="ltr">`3^6`</span>
  - ۲) <span dir="ltr">`2^4 × 3^6`</span>
  - ۳) <span dir="ltr">`2^6`</span>
  - ۴) <span dir="ltr">`3^12`</span>
- **پاسخ تشریحی:** **گزینه ۱ صحیح است.** طبق فرمول <span dir="ltr">`3^(n(n-1)/2)`</span> (چون قطر اصلی به دلیل بازتابی بودن حتماً ۱ است و هر یک از <span dir="ltr">`4 × 3 / 2 = 6`</span> جفتِ غیرقطری ۳ حالت مجاز دارند)، جواب برابر **<span dir="ltr">`3^6 = 729`</span>** است.

---

### تست ۱۳ (آمار و احتمال مهندسی — تابع مولد گشتاور):
- **سوال:** اگر تابع مولد گشتاور متغیر تصادفی <span dir="ltr">`X`</span> به صورت <span dir="ltr">`M_X(t) = (0.4 + 0.6 e^t)^10`</span> و متغیر تصادفی <span dir="ltr">`Y`</span> مستقل از <span dir="ltr">`X`</span> دارای توزیع پواسون با پارامتر <span dir="ltr">`λ = 3`</span> باشد، مقدار <span dir="ltr">`Var(2X - Y + 5)`</span> چقدر است؟
  - ۱) ۶.۶
  - ۲) ۱۲.۶
  - ۳) ۹.۶
  - ۴) ۱۵.۶
- **پاسخ تشریحی:** **گزینه ۲ صحیح است.**
  - از شکل <span dir="ltr">`M_X(t)`</span> مشخص است که <span dir="ltr">`X ~ Bin(n=10, p=0.6)`</span> است؛ پس واریانس آن برابر <span dir="ltr">`Var(X) = n p q = 10 × 0.6 × 0.4 = 2.4`</span> است.
  - برای <span dir="ltr">`Y ~ Pois(3)`</span> نیز واریانس برابر <span dir="ltr">`Var(Y) = λ = 3`</span> است.
  - چون <span dir="ltr">`X`</span> و <span dir="ltr">`Y`</span> مستقل‌اند:
    - <span dir="ltr">`Var(2X - Y + 5) = 2^2 Var(X) + (-1)^2 Var(Y) + 0 = 4(2.4) + 1(3) = 9.6 + 3 = 12.6`</span>.

---

### تست ۱۴ (جبر خطی — جدید ۱۴۰۶ با ضریب ۲ — مقادیر ویژه، اثر و دترمینان):
- **سوال:** ماتریس <span dir="ltr">`3 × 3`</span> واقعی <span dir="ltr">`A`</span> دارای مقادیر ویژه <span dir="ltr">`λ1 = 2`</span>، <span dir="ltr">`λ2 = -1`</span> و <span dir="ltr">`tr(A) = 4`</span> است. دترمینان ماتریس <span dir="ltr">`B = A^2 - A`</span> کدام است؟
  - ۱) ۱۲
  - ۲) ۲۴
  - ۳) ۴۸
  - ۴) ۶
- **پاسخ تشریحی:** **گزینه ۲ صحیح است (`24`).**
  - ۱. طبق رابطه اثر ماتریس: <span dir="ltr">`tr(A) = λ1 + λ2 + λ3 = 2 + (-1) + λ3 = 4`</span> ← پس مقدار ویژه سوم برابر <span dir="ltr">`λ3 = 3`</span> است.
  - ۲. هر مقدار ویژه ماتریس چندجمله‌ای <span dir="ltr">`B = P(A) = A^2 - A`</span> دقیقاً برابر <span dir="ltr">`P(λ_i) = λ_i^2 - λ_i`</span> است:
    - برای <span dir="ltr">`λ1 = 2`</span>: <span dir="ltr">`μ1 = 2^2 - 2 = 2`</span>
    - برای <span dir="ltr">`λ2 = -1`</span>: <span dir="ltr">`μ2 = (-1)^2 - (-1) = 2`</span>
    - برای <span dir="ltr">`λ3 = 3`</span>: <span dir="ltr">`μ3 = 3^2 - 3 = 6`</span>
  - ۳. دترمینان هر ماتریس برابر حاصل‌ضرب مقادیر ویژه آن است: <span dir="ltr">`det(B) = μ1 × μ2 × μ3 = 2 × 2 × 6 = 24`</span>.

---

### تست ۱۵ (جبر خطی — جدید ۱۴۰۶ با ضریب ۲ — رتبه و بعد فضای پوچ):
- **سوال:** اگر <span dir="ltr">`A`</span> یک ماتریس <span dir="ltr">`4 × 6`</span> باشد و برای یک بردار ثابت <span dir="ltr">`b`</span> دستگاه <span dir="ltr">`AX = b`</span> دارای جواب یکتا نباشد، اما برای هر بردار <span dir="ltr">`b ∈ R^4`</span> دستگاه سازگار باشد (حداقل یک جواب داشته باشد)، آنگاه بعد فضای پوچ ماتریس <span dir="ltr">`A`</span> (<span dir="ltr">`nullity(A)`</span>) و بعد فضای سطری آن به ترتیب کدام‌اند؟
  - ۱) ۲ و ۴
  - ۲) ۴ و ۲
  - ۳) ۱ و ۳
  - ۴) ۳ و ۱
- **پاسخ تشریحی:** **گزینه ۱ صحیح است (`2` و `4`).**
  - ۱. چون <span dir="ltr">`AX = b`</span> برای **هر** <span dir="ltr">`b ∈ R^4`</span> سازگار است، تبدیل خطی متناظر پوشا بوده و فضای ستونی کل <span dir="ltr">`R^4`</span> را می‌سازد؛ پس رتبه ماتریس ماکزیمم و برابر با تعداد سطرها یعنی <span dir="ltr">`rank(A) = 4`</span> است.
  - ۲. بعد فضای سطری دقیقاً برابر <span dir="ltr">`rank(A) = 4`</span> است.
  - ۳. طبق قضیه طلایی **رتبه-پوچی (<span dir="ltr">`Rank-Nullity`</span>)**: <span dir="ltr">`rank(A) + nullity(A) = n`</span> (تعداد ستون‌ها = ۶). پس <span dir="ltr">`nullity(A) = 6 - 4 = 2`</span>.

## ۳. تست آرشیوی از دروس حذف‌شده (صرفاً جهت تشخیص در دفترچه‌های ۱۳۹۸ تا ۱۴۰۳)

### تست آرشیوی (پایگاه داده — نرمال‌سازی — حذف‌شده از کنکور ۱۴۰۶):
- **تذکر مهم:** درس **پایگاه داده‌ها** از کنکور کارشناسی ارشد **۱۴۰۶ حذف شده است**. این تست صرفاً جهت عدم سردرگمی شما هنگام رد کردن سوالات ۹۶ تا ۱۱۵ دفترچه‌های ۱۴۰۲ و ۱۴۰۳ در پوشه آرشیو قرار داده شده است.
- **سوال:** در رابطه <span dir="ltr">`R(A, B, C, D)`</span> وابستگی‌های تابعی <span dir="ltr">`AB -> C`</span>، <span dir="ltr">`C -> D`</span> و <span dir="ltr">`D -> A`</span> برقرارند. بالاترین فرم نرمال این رابطه کدام است؟
  - ۱) <span dir="ltr">`1NF`</span> | ۲) <span dir="ltr">`2NF`</span> | ۳) <span dir="ltr">`3NF`</span> | ۴) <span dir="ltr">`BCNF`</span>
- **پاسخ تشریحی:** **گزینه ۳ (`3NF`) صحیح است.** کلیدهای کاندید `AB, BC, BD` هستند، لذا تمام ۴ صفت اصلی (`Prime`) بوده و رابطه در `3NF` است اما چون سمت چپ `C -> D` ابرکلید نیست در `BCNF` نیست.
