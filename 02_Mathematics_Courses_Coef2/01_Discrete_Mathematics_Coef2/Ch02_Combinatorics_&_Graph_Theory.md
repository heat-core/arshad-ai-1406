# فصل ۲ و ۳: ترکیبیات، روابط بازگشتی و نظریه گراف (<span dir="ltr">`Combinatorics & Graph Theory`</span>)

---

## ۱. فرمول‌های طلایی شمارش و ترکیبیات

- **۱. تعداد جواب‌های صحیح نامنفی معادله <span dir="ltr">`x1 + x2 + ... + xk = n`</span> (توزیع <span dir="ltr">`n`</span> شیء یکسان در <span dir="ltr">`k`</span> جعبه متمایز):**
  - فرمول: **<span dir="ltr">`C(n + k - 1, n) = C(n + k - 1, k - 1)`</span>**
- **۲. پریش (<span dir="ltr">`Derangement - D_n`</span> — تعداد جایگشت‌هایی که هیچ عضوی در جای خودش قرار نگیرد):**
  - فرمول: **<span dir="ltr">`D_n = n! * [1 - 1/1! + 1/2! - 1/3! + ... + (-1)^n / n!] ≈ round(n! / e)`</span>**
  - مقادیر مهم پریش که باید حفظ باشید:
    - <span dir="ltr">`D_1 = 0`</span>، <span dir="ltr">`D_2 = 1`</span>، <span dir="ltr">`D_3 = 2`</span>، **<span dir="ltr">`D_4 = 9`</span>**، **<span dir="ltr">`D_5 = 44`</span>**، <span dir="ltr">`D_6 = 265`</span>.
- **۳. حل رابطه بازگشتی خطی همگن با ضرایب ثابت (<span dir="ltr">`a_n = c1 a_{n-1} + c2 a_{n-2}`</span>):**
  - معادله مشخصه را تشکیل دهید: <span dir="ltr">`r^2 - c1 r - c2 = 0`</span>
  - اگر دو ریشه متمایز <span dir="ltr">`r1, r2`</span> داشته باشد: <span dir="ltr">`a_n = α * r1^n + β * r2^n`</span>
  - اگر ریشه مضاعف <span dir="ltr">`r`</span> با مرتبه تکرار <span dir="ltr">`m`</span> داشته باشد: <span dir="ltr">`a_n = (α_0 + α_1 n + ... + α_{m-1} n^{m-1}) * r^n`</span>

---

## ۲. فرمول‌ها و قضایای طلایی نظریه گراف

برای گراف ساده <span dir="ltr">`G = (V, E)`</span> با <span dir="ltr">`v`</span> راس و <span dir="ltr">`e`</span> یال:
- **۱. لم دست دادن (مجموع درجات رئوس):**
  - در گراف بدون جهت: **<span dir="ltr">`∑ deg(v_i) = 2e`</span>** (در هر گرافی تعداد رئوس با درجه **فرد** حتماً **زوج** است!).
  - در گراف جهت‌دار: **<span dir="ltr">`∑ deg+(v_i) = ∑ deg-(v_i) = e`</span>**.
- **۲. گراف کامل (<span dir="ltr">`K_n`</span>) و دوبخشی کامل (<span dir="ltr">`K_{m,n}`</span>) و ابرمکعب (<span dir="ltr">`Q_n`</span>):**
  - گراف کامل <span dir="ltr">`K_n`</span>: دارای <span dir="ltr">`n`</span> راس، درجه هر راس <span dir="ltr">`n - 1`</span>، تعداد یال‌ها <span dir="ltr">`n(n - 1) / 2`</span>.
  - گراف دوبخشی کامل <span dir="ltr">`K_{m,n}`</span>: دارای <span dir="ltr">`m + n`</span> راس و <span dir="ltr">`m * n`</span> یال.
  - گراف ابرمکعب <span dir="ltr">`Q_n`</span>: دارای **<span dir="ltr">`2^n`</span> راس**، درجه هر راس <span dir="ltr">`n`</span>، تعداد یال‌ها **<span dir="ltr">`n * 2^(n - 1)`</span>**، و همیشه **دوبخشی** است!

### ۳. گراف اویلری در برابر گراف همیلتونی
- **گراف اویلری (عبور از تمام یال‌ها دقیقاً یک بار):**
  - گراف همبند دارای **مدار (دور) اویلری** است اگر و تنها اگر **درجه تمام رئوس آن زوج باشد!**
  - گراف همبند دارای **مسیر اویلری باز (غیرمدار)** است اگر و تنها اگر **دقیقاً ۲ راس با درجه فرد** داشته باشد!
- **گراف همیلتونی (عبور از تمام رئوس دقیقاً یک بار):**
  - **قضیه دیراک (شرط کافی):** اگر <span dir="ltr">`n ≥ 3`</span> و درجه هر راس حداقل **<span dir="ltr">`deg(v) ≥ n / 2`</span>** باشد، گراف حتماً همیلتونی است.
  - **قضیه اوره (شرط کافی):** اگر برای هر دو راس غیرمجاور <span dir="ltr">`u, v`</span> داشته باشیم **<span dir="ltr">`deg(u) + deg(v) ≥ n`</span>**، گراف حتماً همیلتونی است.
  - **شرط لازم در گراف دوبخشی <span dir="ltr">`G(X, Y)`</span>:** اگر <span dir="ltr">`|X| ≠ |Y|`</span> باشد، گراف **نمی‌تواند دور همیلتونی داشته باشد!** (و اگر <span dir="ltr">`||X| - |Y|| > 1`</span> باشد، حتی مسیر همیلتونی هم ندارد!).

### ۴. گراف‌های مسطح (<span dir="ltr">`Planar Graphs`</span>) و رنگ‌آمیزی
- **فرمول اویلر برای گراف مسطح همبند:** **<span dir="ltr">`v - e + r = 2`</span>** (که <span dir="ltr">`r`</span> تعداد نواحی شامل ناحیه بیرونی است؛ اگر گراف دارای <span dir="ltr">`k`</span> مولفه همبندی باشد: <span dir="ltr">`v - e + r = k + 1`</span>).
- **نامساوی‌های تشخیص غیرمسطح بودن گراف ساده همبند (<span dir="ltr">`v ≥ 3`</span>):**
  - ۱. در هر گراف مسطح: **<span dir="ltr">`e ≤ 3v - 6`</span>** (نتیجه: گراف کامل <span dir="ltr">`K_5`</span> با ۵ راس و ۱۰ یال چون <span dir="ltr">`10 > 3(5)-6=9`</span> است، مسطح نیست!).
  - ۲. در گراف مسطح بدون مثلث (مثلاً هر گراف دوبخشی مسطح): **<span dir="ltr">`e ≤ 2v - 4`</span>** (نتیجه: گراف <span dir="ltr">`K_{3,3}`</span> با ۶ راس و ۹ یال چون <span dir="ltr">`9 > 2(6)-4=8`</span> است، مسطح نیست!).
- **قضیه کوراتوفسکی:** گرافی غیرمسطح است اگر و تنها اگر شامل زیرگرافی همومورف با **<span dir="ltr">`K_5`</span>** یا **<span dir="ltr">`K_{3,3}`</span>** باشد.
- **عدد رنگی گراف (<span dir="ltr">`χ(G)`</span>):**
  - گراف دوبخشی و درخت‌ها (با حداقل ۱ یال): <span dir="ltr">`χ(G) = 2`</span>.
  - دور به طول زوج (<span dir="ltr">`C_{2k}`</span>): عدد رنگی **۲**؛ دور به طول فرد (<span dir="ltr">`C_{2k+1}`</span>): عدد رنگی **۳**.
  - چرخ <span dir="ltr">`W_n`</span> (یک راس وسط متصل به دور <span dir="ltr">`C_n`</span>): اگر <span dir="ltr">`n`</span> زوج باشد عدد رنگی **۳** و اگر <span dir="ltr">`n`</span> فرد باشد عدد رنگی **۴**.
  - هر گراف مسطح (قضیه ۴ رنگ): **<span dir="ltr">`χ(G) ≤ 4`</span>**.
- **تعداد درخت‌های پوشای گراف کامل <span dir="ltr">`K_n`</span> (فرمول کیلی):** برابر **<span dir="ltr">`n^(n - 2)`</span>** (و برای <span dir="ltr">`K_{m,n}`</span> برابر <span dir="ltr">`m^(n-1) * n^(m-1)`</span>).
